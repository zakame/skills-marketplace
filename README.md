# Zakame Skills Marketplace

Claude Code skills and agent team plugins by Zak Elep.

## Installation

Add this marketplace to Claude Code:

```bash
/plugin marketplace add zakame/skills-marketplace
```

## Available Plugins

### Brooks Agent Team

**Description:** Surgical team collaboration skills for Claude Code, inspired by Fred Brooks' *The Mythical Man-Month*

**Categories:** Collaboration, Code Review, Testing, Agents

**Install:**
```bash
/plugin install brooks-agent-team@zakame-skills-marketplace
```

**What you get:**
- Surgical team roles: Surgeon, Copilot, Tester, Editor, Toolsmith, Language Lawyer, Program Clerk, Administrator
- `/assemble-team` and `/assemble-with-agent-teams` commands
- Agent definitions for Copilot, Tester, and Language Lawyer
- Skills for each team role with structured workflows

**Repository:** https://github.com/zakame/brooks-agent-team
